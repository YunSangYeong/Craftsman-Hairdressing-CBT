# 시험 규칙 확인 상태

미용사(일반)의 공식 규칙을 전기기능사에서 그대로 확인된 사실로 복사하지 않는다. 현재 실행 환경에서 Q-Net 접속이 다음과 같이 차단되었다.

- 2026-10-25, `curl -I -L --max-time 25 'https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7941'`
- 결과: CONNECT 터널 `403 Forbidden`, curl 종료 코드 56.
- 이 URL의 자격종목 코드와 페이지 내용도 직접 읽지 못했으므로 공식 근거로 확정하지 않았다.
- 실제 런타임 정책에는 사용자 추가 도메인이 아직 없으며, 설정 초안 저장만으로 네트워크가 적용됐다고 보지 않는다.

Q-Net 원문·현행 출제기준 파일과 공중위생 관련 법령을 실제 읽지 못했다. 따라서 `src/qualification-profile.json`의 `rulesVerificationStatus`는 `pending`, `officialSources`는 빈 배열이다. 읽지 않은 공식 자료를 출처로 표시하지 않는다.

| 항목 | 현재 학습용 잠정 설정 | 확인 상태 |
| --- | --- | --- |
| 자격증 | 미용사(일반) | 사용자 지정 |
| 시행기관 | 한국산업인력공단 | 공식 원문 직접 대조 대기 |
| 통합 필기과목명 | 헤어스타일 연출 및 두피·모발 관리 | 공식 원문 직접 대조 대기 |
| 문항·시간 | 객관식 4지선다 60문항, 60분 | 공식 원문 직접 대조 대기 |
| 점수·합격 | 100점 만점 60점 이상, 별도 영역 과락 없음 | 공식 원문 직접 대조 대기 |
| 미응답 | 오답으로 처리 | 앱의 학습 정책 |
| 영역별 배분 | 헤어 24 / 두피모발 12 / 피부화장품 12 / 위생안전 12 | 앱의 학습 정책, 공식 출제 분포 아님 |

값은 일반 지식을 바탕으로 한 학습 설정이며 공식 확인 완료나 실제 시험의 완전 재현을 의미하지 않는다. 60문항에서 35정답은 58.3점(표시), 36정답은 60점이다. 합격은 반올림 전 원점수로 판단한다.

선택 정책: 각 영역에서 내부 검토 완료 문항만 추출한다. 각 family는 우선 1개만 선택하고 부족하면 같은 family의 다른 고유 ID로 보충한다. 현재 기본 은행은 영역별 독립 후보가 충분해 family 중복 없이 한 회를 구성한다.

공식 확인을 계속하려면 환경 설정에서 Q-Net·법령 조회 도메인 초안 변경을 검토·저장하여 실제 접근을 허용해야 한다. 이후 공식 자격정보와 현행 출제기준의 과목·문항 수·시간·보기·점수·과락 조건·적용 기간을 직접 읽고 기록해야 한다. 현재 이 검증은 완료되지 않았다. 학습 화면의 상단 상시 배너 대신 문제은행 관리와 이 문서에서 상태를 안내한다.
