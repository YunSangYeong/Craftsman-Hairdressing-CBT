# 문항 작성·내부 검토 기록

대상: 미용사(일반). 기록일: 2026-10-25. 원문 기출 0, 복원 0, 자체 제작 1,000문항.
이 문서는 작성 위치와 검토 범위의 기록이며 외부 정답 증빙이 아니다.

## 실제 데이터 구성

| 학습 영역 | 개념 문항 | 계산 조건 변형 | 합계 |
| --- | ---: | ---: | ---: |
| 헤어스타일 연출 | 50 | 300 | 350 |
| 두피·모발 관리 | 50 | 0 | 50 |
| 피부·화장품 | 50 | 200 | 250 |
| 공중위생·안전 | 50 | 300 | 350 |
| 전체 | 200 | 800 | 1,000 |

문항 수는 `src/data/questions.json`의 실제 항목 수다. ID 및 NFKC 정규화 본문·보기 집합 중복은 0이다. 개인 브라우저 가져오기는 이 수에 포함하지 않는다. 1,000개의 기출, 1,000개의 독립 개념, 공식 시험의 실제 난이도·출제 비율을 확보했다는 뜻이 아니다. 개념 문항 간에도 안전·위생 원리 등 연관되거나 겹치는 학습 내용이 있다.

## 개념 문항 200개

원고는 `scripts/concepts.tsv`에 보존한다. AI의 일반 지식을 바탕으로 새로 작성했으며 특정 교재·공식 출제기준·민간 기출 원문을 읽고 전재한 것이 아니다. 작성 후 원고 전체의 문장, 정답 선택, 보기의 구별 가능성, 설명과 정답의 일치 여부를 저자 내부 검토했다. 같은 AI 작성 주체의 검토이며 독립적인 전문가 검수가 아니다.

제품별 피부 반응 시험 시간·혼합 비율·소독제의 실제 권장 농도 등 공식 수치 확인이 필요한 내용을 임의로 보편화하지 않았다. 이상 반응·질환 의심 상황에서는 진단이나 처방을 단정하지 않고 시술 중단·안전 확인·적절한 의료 안내 원칙을 다룬다. 현행 법령의 특정 수치·기간을 검증했다고 주장하지 않는다.

## 계산 8유형 × 100조건 = 800문항

| family | 학습 내용 | 영역 | 수 |
| --- | --- | --- | ---: |
| stock | 주어진 목표 농도의 원액 필요량 | 공중위생·안전 | 100 |
| water | 같은 희석 조건의 첨가 용매량 | 공중위생·안전 | 100 |
| final | 희석 후 주어진 부피 농도 계산 | 공중위생·안전 | 100 |
| solute | 질량 백분율에서 용질 질량 | 피부·화장품 | 100 |
| blend | 두 용액의 질량 가중 평균 농도 | 피부·화장품 | 100 |
| developer | 문제에 주어진 가상 배합비의 성분량 | 헤어스타일 연출 | 100 |
| batch | 문제에 주어진 가상 배합비의 총량 | 헤어스타일 연출 | 100 |
| length | 신장·수축 없는 가정에서 남은 길이 | 헤어스타일 연출 | 100 |

일부 유형은 동일한 근본 원리를 다른 미지수에 적용한다. 수치 조건 800개를 독립적인 개념 800개로 세지 않는다. 수학 예시의 농도와 배합비는 실제 약제의 선택·혼합·소독 지침이 아니다. 제품 사용에서는 승인된 표시·제조사 지침과 관련 법령을 따라야 한다. 계산형 비중이 높으므로 현재 은행은 공식 시험 전체의 내용 분포를 재현하지 못한다.

생성은 Python Decimal의 `ROUND_HALF_UP`, 시드 `20261025`로 고정했다. `HAIR-C{영역}-{번호}`와 `HAIR-{family}-{번호}`로 안정적인 ID를 사용한다. `scripts/generate-bank.py`를 다시 실행해 JSON·가져오기 양식을 동일하게 재생성했다. 최종 JSON SHA-256:

```
1ba50f00ee0219d70461d9de9633a917cba4ed89cc80e53034b69c5014ed984a
```

`tests/model.test.ts`는 생성 코드를 불러오지 않고 별도 JavaScript 식과 반올림 경로로 800문항을 각각 재계산한다. 정답 번호, 단위, 유일한 수치 정답, 해설의 결과값, 혼합 농도 경계도 확인한다. 입력 조건은 유형별로 100개씩 서로 다르다. 이 수학 검증은 외부 전문가의 문장·개념 검수나 공식 출제기준 대조를 대신하지 않는다.

## 검토 상태의 의미

- 기본 JSON의 `reviewed`: 위 범위의 저자 내부 검토와 해당 자동 검증 완료. 외부 검증 완료라는 뜻이 아니다.
- 가져온 문항의 `pending`: 출처·권한·정답을 검토하기 전까지 실제 출제 대상에서 제외된다.
- 학습 은행 외부 승인·공식 기준 대조: 미완료. 법령 원문과 전문 교재를 확인한 것처럼 인용하지 않는다.
- 과거 기출의 재배포 권한: 확보한 원문 기출이 없으므로 해당 없음.
